# VisionDesk

AI-powered image intelligence — photograph a work site, and a multimodal LLM
identifies the objects so photos become searchable months later.

## Structure

| Path | What |
|---|---|
| `apps/api` | Laravel API — auth, uploads, queues, detection records |
| `apps/web` | Next.js frontend |
| `docs/` | Architecture, schema, decisions |
